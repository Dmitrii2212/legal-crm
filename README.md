# Юридическая CRM

Рабочее пространство для ведения клиентов, судебных дел и контрольных сроков. После входа пользователь видит рабочий стол с задачами и может перейти к клиентам, делам или месячному календарю.

## Демонстрационный запуск на Windows 11

1. Установите Python 3.12, 3.13 или 3.14. Оставьте доступным лаунчер `py` или добавьте Python в `PATH`. [Скачать Python для Windows](https://www.python.org/downloads/windows/)
2. Клонируйте репозиторий или полностью распакуйте ZIP в папку, доступную для записи.
3. Дважды щёлкните `start-demo.bat` или запустите `.\start-demo.bat` из корня проекта в терминале.
4. Когда скрипт запустит сервер, откройте CRM. Для входа используйте логин `demo` и пароль `legalcrm-demo`. [Открыть демо](http://127.0.0.1:8765/)

Скрипт создаёт окружение `.venv-demo`, устанавливает зависимости, применяет миграции и при первом запуске добавляет вымышленные записи. Для установки пакетов нужен интернет. Демо работает без Docker и PostgreSQL. Записи хранятся в файле `demo.sqlite3` в папке проекта и сохраняются при повторном запуске. Для остановки сервера нажмите `Ctrl+C` в его окне.

## Основной запуск с PostgreSQL

Понадобятся Docker и Docker Compose v2. Команды локального запуска выполняются из корня репозитория.

```sh
cp .env.example .env
docker compose up --build --wait
docker compose exec web python manage.py createsuperuser
```

Откройте CRM и войдите под созданной учётной записью. При запуске веб-контейнер применяет миграции PostgreSQL и собирает статические файлы. [Открыть CRM](http://localhost:8000/)

В исходном профиле CRM доступна на локальном компьютере. Порт задаётся через `CRM_PORT` в `.env`. Для другой среды настройте свой `DJANGO_SECRET_KEY`, учётные данные PostgreSQL, разрешённые хосты и HTTPS. При доступе через HTTPS установите `DJANGO_DEBUG=0` и `DJANGO_SECURE_COOKIES=1`. Если нужен доверенный источник для CSRF, перечислите его с протоколом в `DJANGO_CSRF_TRUSTED_ORIGINS`.

## Первый сценарий

1. В разделе «Клиенты» добавьте физическое лицо, ИП или юридическое лицо.
2. В разделе «Судебные дела» создайте судебное дело и выберите клиента. Укажите суд, судью, стадию, участников и ссылки на материалы.
3. Из карточки дела создайте задачу или контрольный срок с датой и временем.
4. Просмотрите её на рабочем столе и в календаре. Из карточек можно открыть формы редактирования и сохранить изменения.

Для ознакомления можно добавить вымышленных клиентов, дела и задачи в подключённую базу данных.

```sh
docker compose exec web python manage.py seed_demo
```

Это общее рабочее пространство одной команды. Все активные пользователи после входа имеют доступ ко всем клиентам, делам и задачам. Часовой пояс интерфейса — `Europe/Moscow`. Администратор может создать дополнительные учётные записи в панели Django. [Открыть панель](http://localhost:8000/admin/)

## Данные и проверки

PostgreSQL хранит данные в томе Compose `postgres_data`. При остановке и повторном запуске контейнеров записи сохраняются.

```sh
docker compose stop
docker compose up -d
```

В основном режиме тесты используют отдельную тестовую базу PostgreSQL. Команды собирают актуальный образ из рабочей копии.

```sh
docker compose run --rm --build web python manage.py check
docker compose run --rm web python manage.py makemigrations --check --dry-run
docker compose run --rm web python manage.py test
```

Для проверки демонстрационного режима запустите тесты из корня проекта после создания `.venv-demo`.

```bat
.venv-demo\Scripts\python.exe manage.py test --settings=config.settings_demo
```

## Структура

- `config/` — настройки, маршруты и точки входа Django.
- `clients/` — клиенты и их реквизиты.
- `cases/` — судебные дела, участники и материалы.
- `tasks/` — задачи, контрольные сроки, рабочий стол и календарь.
- `templates/` и `static/` — общие шаблоны, стили и локальные ресурсы Bootstrap и HTMX.
- `tests/` — проверки пользовательского сценария.

Сущности связаны внешними ключами PostgreSQL. При добавлении внешнего источника можно реализовать отдельный адаптер для получения и преобразования данных, сохранив модели и правила записи в соответствующем приложении Django. Веб-интерфейс использует Django Templates, Bootstrap и HTMX.
