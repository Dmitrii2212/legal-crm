# Работа с репозиторием

## Архитектура

- Проект использует Python 3.12, Django 5.2 LTS и PostgreSQL. Основной способ запуска — Docker Compose из корня.
- Модели и пользовательские действия находятся в `clients/`, `cases/` и `tasks/`. Общие шаблоны и статические ресурсы находятся в `templates/` и `static/`.
- Интерфейс русскоязычный. Обрабатывайте даты и время средствами Django с учётом зоны `Europe/Moscow`. Для действий из календаря и рабочего стола используйте именованные маршруты.
- Для новых закрытых страниц применяйте авторизацию Django. Пользователи входят в единое рабочее пространство команды.
- Изменение сущности и её зависимых записей сохраняйте в одной транзакции. При изменении моделей добавляйте миграции в приложение-владелец.
- Интеграции с внешними источниками размещайте в отдельных адаптерах. Храните ключи и параметры подключения в переменных окружения.

## Проверки

Для разработки скопируйте `.env.example` в `.env`. Используйте вымышленные имена, реквизиты и ссылки в тестах и демонстрационных записях.

```sh
docker compose run --rm --build web python manage.py check
docker compose run --rm web python manage.py makemigrations --check --dry-run
docker compose run --rm web python manage.py test
```
